# 几何峡谷 cyn4 / Geometric Canyon cyn4

Garmin Connect IQ 峡谷山景表盘。

[English](README.en.md)

## 功能

- AMOLED 亮屏显示峡谷山景，光照随日出日落变化，背景反映天气状况
- 时间、日期、温度、电量和可自定义数据字段
- 中文和英文设置，支持 AMOLED 常亮显示
- MIP 设备使用简化显示

支持的设备见 [manifest.xml](manifest.xml)。部分数据的显示取决于设备和可用数据。

## 构建

安装 Garmin Connect IQ SDK 和 VS Code 的 Monkey C 扩展，打开本项目后运行 **Monkey C: Run Without Debugging**。使用 **Monkey C: Export Project** 生成 IQ 包。
