# A 屏背景：07 山体与昼夜、天气

2026-10-03 当前背景以获批 07 的几何峡谷为准。背景阶段后的可靠性修正另涉及 `source/FourthData.mc`、`source/FourthView.mc` 和新增 `source/MoonPhase.mc`：更新位置/时区缓存、改进月相计算、减少重复取数、修复 AOD 连续亮点。字体资源、07 构图、设置和第三代设备范围保留。历史截图保留在验证记录中；最终验证见 `evidence/RELIABILITY-VALIDATION.md`。

## 固定构图与光照

左侧山峰、谷底窄河、右侧陡壁和几何前景不随天气移动。已删除用户圈选的左上悬空切面；崖缘受光收窄并连续接入山壁，不再形成孤立亮块。

清晨使用粉紫上空和柔和金色谷光；白天使用冷蓝天空与浅色远山；黄昏暖色集中谷底、河道和细窄崖缘；夜间保留暗蓝山体、少量星点和月相。天空使用 RGB565 有序抖动，缓和渐变色阶。局部光晕随高度取底色，不覆盖成大块不透明色带。

太阳位置和晨昏配色锚定传入的日出、日落；短冬日晨昏重叠按权重混合。生产数据层使用原生日出日落；日期、时区或位置漂移达到 0.1 度时刷新。天气位置超过四小时不再使用；太阳接口缺值每 60 秒重试，仍保留 06:00/18:00 回退。晨昏 ±75 分钟是视觉过渡，不是天文暮光计算。

## 天气分类

| 状态 | 背景表现 |
|---|---|
| 晴、少云 | 清晰山面；少云降低部分光照 |
| 阴、概率性降水 | 几何云层；降水概率不画实际雨雪 |
| 雨、冻雨 | 低云、细雨线、低饱和湿山面 |
| 雪 | 冷色云、雪点、山脊和前景积雪 |
| 雷雨 | 暗云、密雨、固定闪电切面 |
| 雾、霾 | 远山显著变淡；近崖保留轮廓，无水平装饰雾条 |
| 雨夹雪、冬季混合降水 | 同时出现雨线和雪点 |
| 冰雹 | 菱形冰粒，无雪天积雪覆盖 |
| 沙尘、烟、火山灰 | 暖灰褐色天空和能见度下降 |
| 普通大风 | 风线，保留昼夜光照，不推定阴云或湿山面 |
| 风暴 | 风线与较重阴云；仅热带风暴、飓风叠加雨线 |
| 冰 | 山面结冰亮面，无飘雪 |
| 未知或无数据 | 中性云与保守光照，不当作晴天 |

轻重雨、雪调整粒子密度。Garmin 当前 0–52 条件均有归类；未知和未来编号走未知分支。普通大风与风暴分别处理；单个风条件不能推导真实云量。

## GitHub 月相

直接采用 [Weather Icons](https://github.com/erikflowers/weather-icons) 的 28 阶段原字形，许可 OFL 1.1，署名 Lukas Bischoff、Erik Flowers。源字体、阶段表、来源与完整许可见 `assets/moon`；转换及指纹见 `tools/build-moon-assets.py`、`evidence/moon-asset-source.json`。每次只加载一张小图片，再按屏幕缩放和随光照着色。没有自绘月相轮廓。

采用固定版本 SunCalc 的日月坐标与照明相位计算选择阶段，每 UTC 小时缓存；2026 年 USNO 官方 50 个参考时刻的阶段均通过原生测试。新月隐藏，上弦右亮、下弦左亮。晴、少云或普通大风的深夜显示，阴雨等天气遮挡。此版本未计算月出月落、月亮真实方位或南半球方向，不是完整天文历表。

## 运行预览与验证

`tests/background` 独立调用正式背景，样本日出 06:00、日落 18:00。`single.jungle` 是完整 466px 黄昏；`light`、`weather`、`night-weather`、`classification`、`moon` 是四格预览，每格 233px，分四次更新绘制。`stress.jungle` 在普通 onUpdate 中连续冷启动绘制 35 个全尺寸昼夜天气场景，再运行 28 个全尺寸月相阶段，覆盖真实执行预算。

天空使用两行、两色的棋盘纹理，并缓存每两物理行的颜色；颜色相同时跳过重复计算，每次仍完整重绘。没有完整屏幕位图缓存。休眠释放天空纹理和月相图片；资源不可用时天空回退到色带，月亮缺失不阻止背景和时间绘制。光晕按两物理行绘制、零强度直接跳过。

可靠性阶段通过 17/17 测试和 63/63 设备构建；持续运行、休眠唤醒、AOD 和耗时的最终数据见 `evidence/RELIABILITY-VALIDATION.md`。此前的背景冷启动记录见 `evidence/BACKGROUND-VALIDATION.md`。字段与字体验收仍暂停；真机耗电、真机抬腕切换和 MIP 景色尚未验证或制作。
