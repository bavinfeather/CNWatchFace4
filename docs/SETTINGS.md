# 第四代表盘完整设置（2026-10-04）

手机设置与手表菜单共享同一份 25 项定义。手表通过系统的「表盘 → 设置」进入六组菜单，由 `FourthApp.getSettingsView()` 提供入口；正常表盘模式不自行推入菜单。手机设置的语言由手机决定，表盘与手表菜单另可选择跟随手表、简体中文或 English。选择保存后，返回上一层时立即更新当前值，返回表盘后立即应用。

## 时间、天气与单位

温度保持底部 (84,247)，天气从温度右侧开始排版。中文采用晴、少云、多云、雨、雪、雷雨、雾、未知、雨雪、冰雹、沙尘、风暴、结冰、大风；英文采用 CLEAR、PARTLY、CLOUDY、RAIN、SNOW、STORM、FOG、--、RAIN/SNOW、HAIL、DUST、STORM、ICE、WIND，沿用背景的 14 类分类。关闭文字不影响实时背景天气。

天气原始温度为摄氏，华氏仅在显示时转换：F=C×1.8+32。海拔原始米值只在显示时转换为英尺。切换不会修改缓存原始数据。缺项显示 -- 与当前所选单位。

小时与分钟仍上下两行，保留 Time07 字形。12 小时制正确处理午夜与正午为 12，AM/PM 位于分钟下方；同时开启秒数时，AM/PM 和秒数分开排列。秒数使用系统抬腕后的亮屏刷新，不建立定时器，不请求低功耗每秒重绘。AMOLED 休眠进入现有 SharedAod，时间遵从 12/24 小时与前导零设置；AM/PM 可跟随小日期行显示，秒数始终隐藏。MIP 延续原骨架，接入时间格式、日期开关和亮屏秒数，本轮不制作 MIP 山景或五字段配色。

默认日期仍为 (104,40) 的 22 单位文字；较长的「星期与月/日」格式在必要时缩小防止越界。中英文标签与日期优先使用设备原生字体，旧 AMOLED 使用有完整 OFL 许可的 Noto Sans SC 小字形子集回退，覆盖日期、天气、字段及紧凑数字，不改 Time07、Small、Aod 原字体文件。
