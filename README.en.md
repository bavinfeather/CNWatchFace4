# 几何峡谷 cyn4 / Geometric Canyon cyn4

[中文](README.md)

A canyon-themed Garmin Connect IQ watch face.

- Canyon scenery on AMOLED displays, with lighting based on sunrise and sunset and weather effects
- Time, date, temperature, battery, and configurable data fields
- Chinese and English settings and AMOLED always-on display
- A simplified display on MIP devices

Supported devices are listed in [manifest.xml](manifest.xml). Some fields depend on device capabilities and data availability.

To build, install the Garmin Connect IQ SDK and Monkey C extension for VS Code, open this project, and run **Monkey C: Run Without Debugging**. Use **Monkey C: Export Project** to create an IQ package.
