# Key 收费规则 — 待执行场景

- 无 Key：免费功能持续可用；跨 24 小时、重启、切换表盘后仍无收费提示。
- 手机设置：中文／英文 Key 输入项生成正确，保存后重新读取。
- 时间、日期、电量和 AOD 不依赖 Key；AOD 字体保持一致，AMOLED 按可靠性修正交替区域，MIP 保留原位移。
- 真正校验接入后：空 Key、无效 Key、错误产品或设备的 Key 均不能解锁额外字段设置。
- 有效 Key：仅解锁约定的更多自定义字段设置；免费／付费字段范围待界面设计确定。
- 清空或替换 Key：回到免费设置；已有付费选项需按最终字段规则回退。
- 不能只依靠手机设置页隐藏选项，字段读取／生效也要验证授权。
- 真机重启、换表、重装、退款撤销与离线行为随最终校验方案分别验证。
